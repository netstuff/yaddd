# yaddd
Yet another DDD for Python — the core library.

Framework-agnostic, strictly typed building blocks for layered DDD applications
(domain, application, infrastructure, presentation) with zero dependencies.

See the [monorepo README](https://github.com/pyDDD/yaddd) for quickstart and
[SPEC.md](https://github.com/pyDDD/yaddd/blob/main/SPEC.md) for the layer contracts.
Optional integrations (SQLAlchemy, …) ship as separate `yaddd-*` distributions.
